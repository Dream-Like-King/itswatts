# It’s Watt

A responsive React + Vite + TypeScript landing page for `itswatt.com`.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The **Ask Watt** card is an intentional UI demo. Connect it to a server-side API route before using an AI provider or exposing any credentials.
