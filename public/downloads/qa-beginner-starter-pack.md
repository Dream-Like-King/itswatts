# QA beginner starter pack

## Start here

Quality assurance helps teams reduce avoidable surprises by asking useful questions early and learning from what happens.

## A 30-day starting plan

1. Learn core terms: acceptance criteria, defect, severity, priority, regression, risk.
2. Explore one familiar feature and write down the user goal, expected behavior, and questions.
3. Write one clear defect report using expected behavior, actual behavior, evidence, and impact.
4. Practice an exploratory testing charter for 30 minutes.

## Keep asking

- Who could be affected if this fails?
- What could change after this release?
- What would success and safe failure look like?
- What evidence would help the team act?

Use this as a practical starting point, then adapt it to the product and team you are learning with.
