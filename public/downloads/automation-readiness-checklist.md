# Automation readiness checklist

Use this before choosing a manual check, automated check, AI-assisted workflow, or a combination.

- Is the behavior stable and expected to remain useful?
- Does it run often or protect a meaningful user risk?
- Can the expected result be described clearly?
- Is test data available and safe to use?
- Can the check run without fragile, complex setup?
- Would a failure give the team timely, useful feedback?
- Is exploration still needed for unclear behavior or experience risk?

If most answers are yes, the workflow may be ready for automation. If important answers are no, explore and clarify first.
